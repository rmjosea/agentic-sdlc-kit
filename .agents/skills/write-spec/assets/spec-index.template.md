# Product specifications

## Capability map

| ID | Capability | Status | Depends on |
|---|---|---|---|
| SPEC-<NNN> | [<Capability>](<NNN-capability>/spec.md) | draft | None |

## Status definitions

- `draft`: being authored or awaiting product approval.
- `approved`: behavior and acceptance criteria are confirmed.
- `planned`: an approved technical plan covers the specification.
- `implemented`: implementation is complete but not independently verified.
- `verified`: review evidence confirms the acceptance criteria.
