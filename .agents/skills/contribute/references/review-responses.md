# Responses to review feedback

Load this reference only when preparing an author response to review feedback.
Publishing a response remains a separate, freshly approved action.

Use one of these response forms:

- **Changed with evidence** — state what was actually changed and cite the
  observed check, diff, or artifact evidence.
- **Clarification request** — ask a focused question when the comment or
  requested action is unclear; do not guess at intent.
- **Reasoned technical disagreement** — explain the technical basis and evidence
  for not making the requested change without claiming agreement.

Never mark a thread resolved before the issue is actually addressed under local
policy. Publication of a response and thread resolution are separately and
freshly approved actions under the contribute authorization matrix. The kit
never invents evidence, identities, results, or agreement.
